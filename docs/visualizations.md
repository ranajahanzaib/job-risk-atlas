# Visualization status

The interface contains a procedural 3D schematic mannequin with selectable body regions, an accessible SVG/button fallback, an illustrative movement lab, paginated ORS estimate tables, a numeric source-estimate bar chart, and an occupation landscape scatterplot. These visual models are explanatory navigation, not anatomical measurement or observed worker motion. Charts include labels and source context; source tables remain available for raw values and missingness. The landscape plot includes only numeric estimate and standard-error pairs and does not replace the underlying table. No dummy values or decorative chart marks are presented as evidence. Chart image export, fullscreen charts, and complete keyboard/screen-reader chart alternatives remain unimplemented.
