# Data pipeline status

Implemented: official source URL catalog, retrying download, XLSX ZIP signature check, refusal to overwrite without `--force`, raw XLSX storage, SHA-256 metadata, UTC retrieval timestamp, workbook sheet/dimension/cell-preview inspection, and a streaming ORS 2023 SQLite materializer using the standard library. The materializer validates the expected sheet, six-digit 2018 SOC values, unique series IDs, 128,398 observation rows, and 500 occupation code/title pairs. It preserves estimate and standard-error source strings, raw footnote codes, and source sheet/row provenance.

Not implemented: normalized semantic interpretation of ORS threshold/range estimates, occupation hierarchy, SOC reconciliation to CFOI, CFOI parsing/materialization, Parquet/DuckDB output, and analytical materializations beyond source-defined query views. The current ORS SQLite store is source-faithful rather than a harmonized model. CFOI XLSX acquisition returned HTTP 403; the pipeline supports a manually supplied workbook through `record` and `inspect`, but its actual schema must be reviewed before a parser is written. Build with `python3 scripts/data.py build ors-2023`; validation is written to `data/processed/ors-2023-validation.json`. See `python3 scripts/data.py --help` and [data sources](data-sources.md).
