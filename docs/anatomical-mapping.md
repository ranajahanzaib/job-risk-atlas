# Anatomical activity mapping

## Purpose

The anatomy view is a navigation aid for finding ORS activity labels. It does not estimate anatomical loading, muscle activity, range of motion, injury, or health outcome. The procedural mannequin is an original schematic illustration, not a clinical model or documentary evidence.

## Current qualitative associations

| Body region | ORS activity labels surfaced |
| --- | --- |
| Shoulders | Reaching overhead; reaching at or below shoulder level |
| Arms and hands | Fine manipulation; gross manipulation; handling |
| Neck | No direct anatomical measurement in ORS |
| Trunk | Stooping; lifting; carrying; sitting |
| Legs and feet | Standing; walking; kneeling; crouching |

These associations are editorial groupings for discovery. They are not a validated biomechanical crosswalk. When an occupation is selected, the inspector displays only matching ORS labels and their original published values and provenance. A missing match remains unavailable, never zero.

The current region taxonomy is deliberately broad. More detailed region segmentation and front/back/skeletal views remain future work. The 2D SVG and ordinary HTML region controls preserve access when WebGL is unavailable.
