# Design system

The React dashboard uses a dark industrial palette with restrained cyan and amber accents; compact monospaced metadata; clear source/release labels; and thin structural borders. At narrow widths, the fixed desktop rail becomes a mobile navigation bar and tables scroll horizontally. A light theme is available and saved locally. Reduced-motion preferences are respected. Charts are lazy-loaded and retain source notes alongside the plot.

The procedural 3D mannequin and SVG body map are navigational illustrations only. Region selection is also available through ordinary HTML buttons, so body-area navigation does not depend on WebGL or SVG interaction. Data states use text labels and em dashes alongside color. The current implementation has not had formal WCAG 2.2 AA review.
